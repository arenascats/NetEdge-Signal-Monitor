# 网络状态监测工具

一个基于 Python + Tkinter 的桌面网络状态悬浮工具，支持贴边收起、三色信号灯、IPv4 显示和开机自启。

## 主要功能

- 局域网 IPv4、公网 IPv4 实时显示
- 外网连通性与延迟检测
- 三色边缘灯状态提示
  - 绿: 外网可达
  - 黄: 外网不可达但局域网可用
  - 红: 局域网不可用
- 贴边吸附与自动收起
- 鼠标移到边缘灯自动滑出
- 设置持久化（`settings.json`）
- 可选开机自动启动（Windows）

## 目录结构

- `网络状态监测工具.py`: 主启动入口
- `main.py`: 兼容入口（内部转到主入口）
- `monitor/app.py`: 主界面与交互逻辑
- `monitor/network_service.py`: 网络检测服务
- `monitor/settings_service.py`: 设置读写服务
- `monitor/startup_service.py`: 开机启动注册表服务
- `monitor/constants.py`: 默认常量与预设

## 运行方式

1. 安装 Python 3.10+
2. 在项目目录执行:

```powershell
python 网络状态监测工具.py
```

## 设置说明

在主界面点击齿轮进入设置，可调整:

- 刷新间隔
- 贴边吸附距离
- 自动收起延迟
- 启动默认贴边方向
- 启动时是否自动收起
- 窗口置顶
- 开机自动启动
- 边缘灯样式（竖条/圆形，不同尺寸）

## 注意事项

- 本工具目前面向 Windows（开机自启依赖注册表）。
- 如需关闭开机自启，请在设置中取消勾选后保存。
